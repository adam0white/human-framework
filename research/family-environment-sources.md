# Heredity, upbringing, partnering and environment: empirical sources

Research gathered 2026-10-04 by one subagent pass (Europe PMC and Crossref records, mostly abstracts); a second pass the same day re-checked authors, years, venues, DOIs and findings for every row and the corrections below were applied. Where a row says unconfirmed, the abstract or book could not be retrieved for HF 2.0 L2–L4; written up the same day. Status: an evidence screen for engineering parameters, extending [empirical-models.md](empirical-models.md) §7–8, not a systematic review. Status key: **F** record fetched; **S** number seen only in a search snippet; **U** unverified. An abstract that gives no effect size is not evidence the paper reports none. IDs (F1…) are cited from module doc comments.
