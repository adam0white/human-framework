# Prayer windows and disliked (makruh) times: source record

Research gathered 2026-10-04 by a subagent web pass; written up the same day. Status: a sourced record of what named sources say, not a ruling and not a qualified Hanafi review. It answers the HANDOFF deferred question on the Fajr window and supplies the kerahat bound that the Eid prayer window ([eid-and-mourning-sources.md](eid-and-mourning-sources.md) §1) depends on.

How to read the tiers below (see [source-method.md](source-method.md)):

- **Revealed / transmitted:** Qur'an and hadith. None were re-checked in this pass.
- **Classical Hanafi:** al-Asl, al-Mabsut, Badai al-Sanai, al-Hidaya, al-Ikhtiyar, Radd al-Muhtar and so on. **No classical text was read directly.** Every classical title below is "cited via" the secondary page named next to it. al-Hidaya, Nur al-Idah and Maraqi al-Falah are **unsourced** for these points: no page fetched cited them, and one PDF that might have (the almarifahfoundation PDF in §4) came back unreadable and was not retained.
- **Contemporary Turkish Hanafi:** Diyanet (Din İşleri Yüksek Kurulu pages at kurul.diyanet.gov.tr, the calculation site vakithesaplama.diyanet.gov.tr) and TDV İslâm Ansiklopedisi.
- **Hanafi fatwa sites:** SeekersGuidance and islamqa.org mirrors (the path segment names the issuing body, e.g. `fatwa-tt`, `qibla-hanafi`, `mathabah`, `darululoomtt`).
- **Other schools:** noted where a source gave them; islamweb.net is not a Hanafi site.
- **Engineering assumption:** marked as such; carries no borrowed authority.

**Quote caveat.** The pages reached the researcher through a summarising fetch tool. English "quotes" are close paraphrases of the page unless shown in quotation marks; Turkish in quotation marks is literal as the tool returned it. Check anything load-bearing against the page. Three Diyanet pages were re-fetched on 2026-10-04 during the write-up (marked "re-checked"); that re-check also went through a summarising fetch, so it confirms consistency, not verbatim text.

## 2. Conflict: where Maghrib ends (red or white shafaq)

Hanafi sources disagree. **No source read says which position is dominant.** Record this as disputed.

- **White (Abu Hanifa).** [TDV "Vakit"](https://islamansiklopedisi.org.tr/vakit) defines the shafaq as "kızıllıktan sonra ortaya çıkan beyazlıktır" and ends Maghrib "batı ufkundaki şafağın kaybolmasıyla"; no classical citation isolated for this point. [islamqa darululoomtt 147719](https://islamqa.org/hanafi/darululoomtt/147719/grace-period-for-performing-salaah/) starts Isha when the "white crimson" is gone. [islamqa qibla-hanafi 43601](https://islamqa.org/hanafi/qibla-hanafi/43601/) attributes whiteness to Abu Hanifa.
- **Red (the Sahibayn, Abu Yusuf and Muhammad).** [islamqa fatwa-tt 134062](https://islamqa.org/hanafi/fatwa-tt/134062/salaah-timings-according-to-the-hanafi-madhab/) has Maghrib "until Ash Shafaq Al Ahmar" and calls this the preferred position for rulings (citing Durr al-Mukhtar with Ibn Abidin). The 43601 fatwa (Darul Uloom Karachi, per the tool) says Isha "can be performed after the disappearance of redness".

**Engineering consequence:** the framework takes Maghrib-to-Isha boundaries from the host calendar. Neither position is encoded; a host that tabulates Isha has chosen one, and should say which.

## 5. Engineering mapping (assumptions, not rulings)

- The framework's `prayerWindow` (packages/human/src/agenda/prayer.ts) runs each window to the next prayer, so Fajr runs to Dhuhr. The sources above (TDV, the Hanafi fatwa sites, and Diyanet's 7-minute sunrise temkin) put the end of Fajr at sunrise. Ending Fajr at Dhuhr is therefore a simplification that the sources contradict, and the window as coded also covers the sunrise kerahat.
- Isha running to the next day's Fajr matches the Hanafi validity bound; the makruh-after-midnight distinction is not modelled.
- Which kerahat length (Diyanet 40-50 min, or about 20 min elsewhere), which Asr (Diyanet's asr-ı evvel or Abu Hanifa's two lengths) and which shafaq a host uses are host choices to be labelled as such. The town scenario is set in Turkey, which makes Diyanet's conventions the natural default for it; that is an engineering choice, not a finding.

## 6. A prayer begun in its time (added 2026-10-04, Game 2 twelfth pass)

| Claim | Tier | Source | Status / notes |

| Hanafi: sunrise during Fajr invalidates it (made up after sunrise); Asr finished after sunset is still valid | Fatwa site (Hanafi) | [SeekersGuidance](https://seekersguidance.org/answers/hanafi-fiqh/is-my-prayer-valid-if-i-finish-praying-outside-its-respective-prayer-time/) | Fetched. | Delaying on purpose so that part of the prayer falls outside its time is a sin, though the prayer counts; the one-rak'ah rule rescues someone who forgot or overslept | Fatwa sites | islamweb 331408 above; abukhadeejah above | Fetched. Engineering mapping: the agenda keeps a commitment open while an act that serves it, begun inside the window, is under way (`agenda.underWay`), and the will's omission rule protects it for that time (`will.closingDuties`). "Begun inside the window" stands in for both the takbir and the one-rak'ah positions; the framework does not count rak'ahs.
