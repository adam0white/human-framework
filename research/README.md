# Research

Source records behind HF's norms, formulas and decisions. Code doc comments, `NormDef.sources` and [decisions.md](decisions.md) cite these files by name, so rename or move one only together with its citations. Each file states its own date and status; none is a ruling.

## Decisions

- [decisions.md](decisions.md): contested religious points, decided on the user's direction (most common position overall, post-sectarian, pragmatic). Code cites it.

## Faith and norm sources

- [norm-sources.md](norm-sources.md): review status of every norm in the catalog and where its sources are.
- [islamic-foundations.md](islamic-foundations.md): the faith constraints on the framework (what it must never compute or name).
- [prayer-times-sources.md](prayer-times-sources.md): prayer windows and disliked times.
- [fasting-sources.md](fasting-sources.md): Ramadan fasting, illness, fidya, suhoor, tarawih.
- [eid-and-mourning-sources.md](eid-and-mourning-sources.md): Eid, zakat al-fitr, grave visits, condolence.
- [capacity-and-excuse-sources.md](capacity-and-excuse-sources.md): prayers and fasts missed while not in control of oneself.
- [marriage-sources.md](marriage-sources.md): marriage, courtship, widowhood.
- [cooperation-boundary.md](cooperation-boundary.md): what a cooperation record means; source for `keep-promise`.
- [duty-repair-sources.md](duty-repair-sources.md): entrusted property and repair (v0-era source record, kept for its sources).

## Empirical sources

- [empirical-models.md](empirical-models.md): the evidence screen (§n, S-numbers) that module doc comments cite.

- [learning-through-work.md](learning-through-work.md), [learning-source-followup-2026-09-07.md](learning-source-followup-2026-09-07.md): learning by doing; cited by the faculty inventory.
