# Learning-data alternative feasibility check

Checked 2026-09-08 against the [pilot proposal](learning-data-pilot-proposal.md). This lane inspected primary-source metadata, methods, archive file inventories, source preprocessing, and an 8,192-byte SQLite header. No participant curves were fitted, no model was selected, and no runtime or public app changed. These are availability dispositions, not empirical results.

## CogCarSim: a usable archive route, pending full admission checks

The 2019 paper's own cited archive, [Figshare 7268387](https://doi.org/10.6084/m9.figshare.7268387), does **not** supply chronological performance trials in its declared inventory. Versions 1 and 2 list the same two RData files: participant-level Flow/learning-slope/blink-rate summaries and adjusted p-values. Its CC BY 4.0 license is explicit. Neither file was downloaded: those summaries cannot establish individual learning trajectories. [Captured metadata](../artifacts/learning-pilot/alternative/figshare-7268387.json) and [version 1](../artifacts/learning-pilot/alternative/figshare-7268387-versions-1.json).

A bounded check of the authors' [hipercog/flowcar repository](https://github.com/hipercog/flowcar) found its README's link to a later [Figshare 13567409 v3 archive](https://doi.org/10.6084/m9.figshare.13567409.v3). That item explicitly applies **MIT** and identifies separate SQLite game-log databases for nine 2017 and nine 2019 participants. It accompanies the [2021 replication paper](https://doi.org/10.1016/j.chb.2021.106891). Raw game logs, background profiles, self-report files, derived learning variables, and analysis code are separate downloads. The archive is a different source from the insufficient 2019 citation; do not silently substitute its data or license. [Metadata and original file MD5 declarations](../artifacts/learning-pilot/alternative/figshare-13567409.json).

The [2019 primary methods, sections 2.2–2.4](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.01126/full) describe nine participants, five runs per session, eight sessions on different days over 2–3 weeks. Runs lasted approximately 2–4 minutes. Participants steered through randomly placed obstacles on nearly equal-length tracks. The game increased speed automatically; collisions reduced it, with a subsequent immunity interval. Thus duration records a closed-loop speed/accuracy outcome. Sensor procedures also differed by session: physiological recording occurred in sessions 1 and 5–8. This supports a bounded game-performance question; it does not isolate a biological learning rate, constant difficulty, fatigue, or forgetting.

Actual limited inspection established:

- HTTP 206 delivered bytes 0–8191 of `cogcarsim2_2017.db`, whose declared complete size is 466,171,904 bytes. The SQLite signature and three table definitions are present. The partial-byte SHA-256 is `f3d929c3152b17c09542d8d0cc8a45867d0e22f74c5aff617dd728e679aa75b6`. This is **not** the hash or an integrity check of the complete database. [Range receipt](../artifacts/learning-pilot/alternative/cogcarsim2_2017.header.json).
- The `run` schema includes participant, date, task, seed, collisions, speed drops, duration, distance, steps, version, and description. The `step` schema includes within-run time, position, collision and velocity. [Extracted schema](../artifacts/learning-pilot/alternative/cogcarsim2_2017.schema-extract.json). No participant rows were decoded or retained.
- The authors' [archived Rmd](https://ndownloader.figshare.com/files/27512372), lines 49–96, reads `run`, filters extra test runs, parses a participant/session/run code, sorts those fields, and constructs cumulative run count. This is a proposed chronology route, **not a verified count**. Source comments at lines 933–937 identify one absent game-data record (participant 8, session 6, run 1). The authors' `row_number()` therefore must not be copied as an exposure count without checking missing runs.

**Disposition:** retain the later archive as a credible reserve candidate; neither reject it as aggregate-only nor call it fully admitted. If selected, download only a needed game database, verify its full hash, and inspect the complete `run` table for deidentification, numeric units, duplicate/missing scheduled runs, actual participant count, test-run exclusions, task/version differences, and duration validity. Keep questionnaire/background/physiology data out of the pilot. A missing performed run is missing exposure and must not silently compress dose. Preserve scheduled session/run positions where validated, and distinguish observed prior driving time from total prior practice. Break intervals and the speed controller remain observation-link limits. Freeze all resulting choices before fitting.

## ADM/Lumosity 2024: not admitted in this bounded check

The [2024 primary paper](https://www.nature.com/articles/s43588-024-00629-0) distinguishes simulated-law evaluation from application to Lumosity data. Its approach first estimates cognitive state using a neural network, then derives symbolic expressions. Its plotted mastery curves are therefore model products, not automatically observed participant performance.

The complete [author repository tree](https://github.com/ccnu-mathits/ADM), captured with tree identity `9a0a711889390aa75b88ffcb2f0eef802048b99e`, lists an empty data area except for a README, simulation-result CSVs, and code. No license file appears in that tree. The [Dataset README](https://github.com/ccnu-mathits/ADM/blob/main/Dataset/README.md) redirects to a [Google Drive archive](https://drive.google.com/file/d/1iN2SculPeAjInIpkisDL-LQT0rGsdIQg/view?usp=drive_link). The [real-data README](https://github.com/ccnu-mathits/ADM/blob/main/Real_world_dataset_application/README.md) explicitly describes estimated learner states and generated symbolic equations as outputs. Neither output class was treated as raw observations.

Attempts to read [Zenodo 10938670](https://zenodo.org/records/10938670) and its API returned access/fetch errors or timeouts in this environment. The Drive page also failed to open in the web tool. These are local retrieval failures, not proof that data are unavailable everywhere. Raw-data licensing, deidentification, original performance units, dose, participant chronology, task changes, and score construction were not established. No data archive, model outputs, or supplementary figure tables were downloaded. **Disposition: not admitted; stop this lane with the concrete provenance/licensing/schema gaps.**

All saved source URLs, captured hashes, download scope and access failures are recorded in the [artifact manifest](../artifacts/learning-pilot/alternative/manifest.json). The root pilot selection can compare this reserve with other independently checked candidates on data suitability; published fit outcomes are not a selection criterion.
