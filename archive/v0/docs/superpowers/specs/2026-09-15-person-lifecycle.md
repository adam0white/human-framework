# Unified developing-person lifecycle

The four newly implemented capabilities expose a remaining reuse gap: both consumers manually synchronize observed clocks and assemble owner-checked component snapshots. The user authorizes continuing across gaps. Add a unified private person lifecycle over the unchanged sustained, cognition, relationship, duty, adult-course and appraisal components.

The composite has one actor identity and one observed-minute clock. Calendar-day gaps remain explicitly separate and cannot advance physiology. Sustained-person remains the sole body/action/learning owner. The wrapper advances other observed-time components after each actual advance and returns a detached validated state atomically. Pending actions prevent daily/calendar advancement and conflicting state commands.

A bounded last-attempt receipt is derived from the real pending Human attempt on finish. The regulation command consumes that receipt instead of accepting a caller's fabricated paid duration or attempt ID. It must be completed, at the current time, associated with the current actor and matching reflection action. World outcomes and message delivery remain host-attested; the wrapper cannot create resources or force recipients.

Explicit commands delegate to component APIs, using internal actor views for appraisal and qualification rather than trusting a host to resynchronize views. Failed commands leave the original unchanged. Persistence validates every selected component, identity, chronology and the last attempt boundary. Both direct component APIs and the new composite remain available; frozen releases are unchanged.
