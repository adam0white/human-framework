## External model review

One focused, tools-disabled, source-only Claude CLI default call (no --model) completed on actual **claude-opus-5[1m]**, with auxiliary Haiku usage recorded. The initial --bare attempt had no usable authentication and zero API tokens; it is not counted as a review. The successful restricted call received only frozen candidate 0.1.0 source and the API prefix, no host implementations, other reviews, original user feedback or player exports. The CLI reported about $0.695 of token cost within a $2 ceiling. [Prompt/result/provenance](../../research/reviews/2026-09-08-work-progress-opus/).

- Its terminal-exposure finding independently agrees with the executed Astra counterexamples. Its proposed aggregate-shortfall repair was insufficient; the implemented correction uses a globally possible positive terminal exposure and other physical bounds.
- Repeated prepareWorker input remains range checked: the declared API ignores a different **valid** proposed basis, not arbitrary invalid input. This is a contract choice, not the reported live resume defect.
- Node versions below 22 and foreign-realm object prototypes are outside this package's tested support. Standalone API documentation now states Node >=22/built-in structuredClone explicitly; no extra legacy clone layer was added.
- The 1e-10 consistency allowance remains explicit. Arbitrarily tightening it was not needed to fix the demonstrated whole-minute credit defects.

The Opus review covers the original source, not the corrected implementation. Source-specific executed Astra checks and root verification cover the corrections.
