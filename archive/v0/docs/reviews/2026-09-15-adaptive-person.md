# Adaptive-person review disposition

The lead used three bounded subagents (GPT-5.6-sol, medium) for habits/revision, functional constraints/composite lifecycle, and institution/package work. Separate cross-reviews covered state integrity and causal evidence. Review stayed within subagents because the repository is private. These are engineering reviews, not empirical or qualified theological evaluation.

## Verified findings and fixes

- **Unauthorized facility requests exhausted capacity history.** A denied request consumed the lifetime accepted-request budget. Permission rejection now leaves that budget unchanged; a one-slot regression verifies a denied actor cannot block a later granted request.
- **Restriction notices lost identity.** Clearing one of multiple restrictions on the same demand did not identify which restriction cleared. Notices now carry `restrictionId`, and an overlap regression preserves the other restriction.
- **Non-JSON array properties survived functional restoration.** Array validation now rejects extra properties/accessors; method duration is a positive integer consistent with the sustained lifecycle.
- **Default adaptive view rejected its own null cue.** A missing cue now returns no habit suggestion. Known cue queries still use the validated habit selector.
- **Impossible composite histories could restore.** Paid receipt ordinals must precede the Human attempt counter, and the latest paid receipt must agree with the current last actual attempt. Pending context, clock mismatch and stale review after a calendar interval have explicit tests. This is structural consistency, not history authentication.
- **Habit training ignored the attempt's purpose.** A successful same-cue action under an unrelated purpose could count. Training now requires the captured purpose; a same-cue mismatch resets the streak. A failing regression preceded the fix.
- **The direct habit control mishandled other cues.** Its history is now filtered to the queried cue, and an interleaved-cue case verifies parity.
- **Continuation kept host ledgers in memory.** Checkpoints now JSON-round-trip world, inbox, trace and direct history alongside actor and canonical component states. The reference still supplies the surrounding scenario commands; it is not a persisted autonomous scheduler.
- **Route failures were supplied directly by the loop.** A canonical closed-route condition now settles paid walk attempts as failed. Habit history cannot manufacture the outcome.
- **Installed reuse covered too little new behavior.** The independent consumer now executes paid habit training, failure/review/acceptance, whole-person resume, an accommodated paid method with actual resource use, and paid work after facility promotion.
- **A roadmap sentence still called continuous days missing.** It now points to the sustained-person delivery.

## Preserved limits

The direct arms override controller decisions while carrying the candidate execution/state layer; they are equally informed policy controls, not full module-absent ablations or authoring-cost measurements. The reference exercises a first purpose revision only; module tests cover failure-evidence consumption and overlapping revisions. Cue and purpose labels are supplied by the host at attempt begin, not authenticated inward intention or independent perception.

The inherited Human body uses floating-point arithmetic. Split/whole advancement is checked at 1e-12 for body values and exactly for other state; identical save/resume commands remain exact. No frozen component was changed to conceal this existing tolerance.

Functional methods and institutional allocation are bounded authored opportunities, not clinical recovery or general institutions. Passing tests cannot close the broader human framework. The review identified no need for external services, games or renewed scheduled work.
