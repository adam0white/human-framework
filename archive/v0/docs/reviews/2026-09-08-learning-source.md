I inspected that source boundary, not a fresh production deployment.

Its chronology, finite-field, nonnegative-distance and coordinate-identity checks at lines 40–90 only populate a report, and line 103 overwrites that report. The executable pilot must independently assert the frozen conditions and stop before fitting on failure, as protocol line 14 already requires. I did not execute the report writer or change its output.

3. **Precisely describe the original exclusion if it is discussed.** The archived `Experiment 1a.Rmd:82–86` rounds the fitted slope to four decimals; lines 98–115 retain a participant only when that rounded slope is below zero. “Nonnegative fitted slope” omits that implementation detail. The protocol correctly identifies this as a new chronological secondary comparison rather than independent validation. Keep the stronger all-55 qualification in the eventual interpretation.
