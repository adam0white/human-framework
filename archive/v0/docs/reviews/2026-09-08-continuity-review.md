Some Fable hypotheses did not require a new change. Deniz's exact refusal already appears in persistent time-status through existing session code. These are scoped dispositions, not claims that a generic adapter or every future host is safe.

Actual screen-reader announcements, Safari/physical mobile devices, measured human authoring benefit, calibration and qualified theological review remain unverified.

The work fixture accepts idle/assembly imports only and has no complete gathering/controller/Rain integration.
