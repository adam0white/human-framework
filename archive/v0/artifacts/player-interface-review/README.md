# Independent interface review artifacts

Original findings, fixes, screenshots, paired-state comparisons and final late-delta checks are preserved here. Synthetic saved games are browser QA, not human play evidence.

The four complete source snapshots are compressed to keep duplicate code out of ordinary repository searches. Extract each `source.tar.gz` in its own containing directory to restore the original `source/` tree. Every original file was checked byte-for-byte before compression; `source-archives.json` records archive hashes and counts. Original tool paths in logs identify where the review actually ran. The named snapshot hashes remain authoritative; do not substitute current source when reproducing an earlier finding.
