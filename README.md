# Human Framework

[![CI](https://github.com/adam0white/human-framework/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/adam0white/human-framework/actions/workflows/ci.yml)

Human Framework v1 is a deterministic, explainable model of a simulated person written in TypeScript. A person has a body, needs, emotions, memory, beliefs, habits, relationships, values and a will. They weigh many urges, including outside suggestions, and choose an action. Every choice can be explained, and the person may refuse a suggestion.

- **Live games:** [human.adamwhite.work](https://human.adamwhite.work)
  - [Twice at the Well](https://human.adamwhite.work/colony/): a colony sim played before and after the framework.
  - [The Day You Say Nothing](https://human.adamwhite.work/voice/): your input is a suggestion, and the character can override it.
- **Package:** [`packages/human`](packages/human) (`@human/framework` 1.1.0). See its [README](packages/human/README.md) and [examples](packages/human/examples).
- **Docs:** [architecture](docs/framework.md), [faculty inventory](docs/faculty-inventory.md) (what HF models and what is missing), [API reference](docs/api.md) (regenerate with `npm run api-doc`), [findings](docs/findings.md), [game design notes](docs/games).
- **Site:** the games are in [`apps/site`](apps/site) (React and Canvas, built with Vite and deployed as a Cloudflare Worker).
- **Workflow:** `npm run check` runs lint, typecheck and tests, with no wall-clock assertions. `npm run bench` runs the timing budgets (`*.timing.ts`: village 20 and 50 people for 30 days, body-threshold search, Game 1 full run and balance runs, Game 2 12-day skip) one file at a time and prints each measurement; run it alone on a quiet machine (`BENCH_SCALE=3` multiplies every budget). `npm run bench:hyperfine` times the headless village run (`scripts/bench-village.ts`, 20 people for 30 days, including Node start-up) with [hyperfine](https://github.com/sharkdp/hyperfine) (`brew install hyperfine`). Contributor rules are in [AGENTS.md](AGENTS.md), and current status is in [HANDOFF.md](HANDOFF.md).
- **CI:** [`.github/workflows/ci.yml`](.github/workflows/ci.yml) runs on pushes and pull requests to `main` with Node 26. The `check and build` job (`npm ci`, `npm run check`, `npm run build`) is the gate. The `bench` job is informational: it runs `npm run bench` with budgets at 3× (shared runners are slower and noisier than the machine the budgets were set on), so a missed budget marks its step failed without failing the job, and it writes the measurements and a hyperfine table of the headless village run to the job summary. The repository is private, so the badge above may not render outside a signed-in GitHub session.
- **Releases:** HF versions follow [the version policy](packages/human/README.md#versions); changes are in [CHANGELOG.md](CHANGELOG.md). `npm run release` (on a clean, pushed `main`) checks versions and the changelog, runs `npm run check`, tags `vX.Y.Z` and creates the GitHub release with the package tarball; `npm run release -- --dry-run` stops after packing.
- **Provenance:** the earlier v0 layered-candidate codebase is archived under [`archive/v0/`](archive/v0) (tag `v0.16-final`). It is not built or maintained.
