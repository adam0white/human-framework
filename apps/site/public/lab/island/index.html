Island / experiment notebook

Two minds, one island.

An HF person and a language model explored the same island, with the same observations, legal actions, steps and resets. Three free episodes preceded one task: put cubes on the Spire. This is an experiment, not a game. The HF arms are deterministic and replay exactly from the same seed and state. This viewer shows recorded frames; it does not run a mind.
