# Across the Cut private comparison

2026-09-08 development report. **No public game or general cognition component is justified by these outcomes.** The actor-local host supports legitimate different observations and paid coordination, but a cheap one-way factual report already achieves the highest service count observed in every development configuration. Optional confirmation changes paid messages without changing service in the tested policies. These are authored software cases, not human or empirical evidence.

Reserved evaluation remains sealed pending final independent core/contract review and a committed source freeze. This report will record those results separately when authorized by the integration owner; the development results are not represented as reserved evidence.

## Knowledge, contributions and matched scripts

The controllers receive only a detached actor-local view and detached own policy state. Both decisions are computed before either command is dispatched at the same minute. Own completed transmission time plus the public reliable maximum delay licenses a receipt inference; lossy channels never turn silence into refusal. The inference is recorded, but no measured benefit is attributed to it. The retained last-report arm keeps the latest report across busy work; it is **not** a no-retention model. No acknowledgment gates release, attendance or water receipt.

The current notebook chooses its proposal after finishing own repair and budgets a complete reliable-bound round trip plus optional confirmation time. In these cases, that leaves no feasible long/lossy-channel proposal exchange; its retry branch never fires. This is a limitation of the implemented schedule, not a proof that receipt confirmation can never help. Earlier proposals or releasing before a response are physically legal and were not exhaustively searched. The negative result rejects promotion from this evidence; it does not prove every possible notebook/confirmation policy redundant.

The eight scripted interventions are separate from autonomous policy outcomes. S1 final confirmation and S2 an equal-cost own-consent response have identical actual service, bodies, paid work and supplies. Neither carries a fresh readiness report. Because their physical actions are prescribed identically, they establish cost/physical parity, not a confirmation-induced decision improvement.

S3 preserves an old revision1 acceptance arriving after a revision2 acceptance; exact-revision bookkeeping keeps both. S4 sends an old progress0 report that arrives after progress1: the source-time notebook retains1, while last-arrival bookkeeping overwrites it with0. Both representations process the exact same actor-local received inputs and paid world journal; their physical outcome is therefore identical. This verifies a mundane timestamp/revision bookkeeping obligation. The older private memory candidate is neither changed nor imported.

S5 omitted attendance expires; the withdrawal variant retains explicit withdrawal instead. Both physically supply one cart unit and lose two unattended pipe units. An acceptance never performs its promised labor. S6 achieves paid direct contact service at25 with real travel and return. S7 cancels radio before any integer minute elapses, consumes no radio charge and earns no transmission exposure; its interrupted repair preserves two paid minutes, the installed fitting, and subsequent completion. Do not describe that cancellation as positive partial radio exposure.

Each compressed JSON artifact contains initial/final strict saves and hashes, the complete replay journal, both actors' full local decision inputs in a content-addressed dictionary, controller states/decisions, all messages and consent, resources, body costs, actual service/loss and same-input representation projections. Replay verifies every transition hash, recreates both decision inputs and policy outputs, and imports/resumes mid-run. Hashing complete views is not a selected-facts substitute for recording them.

[Initial Node22 replay](../artifacts/across-cut/development-initial-node22-replay.json) and [corrected Node22 replay](../artifacts/across-cut/development-corrected-node22-replay.json) each validate all80 journals using the exact original Git source graph, not current replacement physics. Run `node scripts/across-cut-replay-history.js --input artifacts/across-cut/development-initial.json.gz --out <fresh-output.json>` to reproduce the older history. The output refuses overwrite; original source hashes and every local import are verified before loading. Ten comparison/provenance tests and all23 core tests pass on Node26.8.1 and minimum Node22.0.0.

The private feasibility boundary is useful engineering evidence. It does not establish a novel memory, attention, planning, social faculty, calibrated human behavior, theological claim, human enjoyment, independent authoring benefit or public-game readiness. The receipt-confirmation premise remains rejected by the executed development evidence; factual report timing may remain a narrower design option. Reserved evaluation, independent review and final source/freeze verification remain the next completion checks.
