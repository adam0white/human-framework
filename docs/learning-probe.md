# Demonstrated conditional methods

The repair-game owner authorized autonomous progression to apprenticeship and beyond on 2026-10-10. The proposed generic HF increment is bounded conditional method acquisition from attended demonstrations. The package owns acquired method state and its influence on ordinary decisions; a host owns the meaning of its cues, valid actions and world outcomes.

## Released-package gap

HF 2.1.4 supports scalar skill gains through instruction/watching, action/target outcome expectations, propositional beliefs and remembered advice matching an action or offer id. These mechanisms do not acquire a demonstrated conjunction of observations selecting an arbitrary next action. Using a host repair switch gated by a skill/training threshold would not meet the game's learning goal.

## Bounded proposal

A person can attend a demonstrated step: method id, finite observable cue conditions, action id, teacher/source and success feedback. Store a bounded, plain-JSON set of acquired conditional rules and evidence. A query reads applicability against received cues; normal cognition includes the acquired rule term for offered actions, with trace provenance. Unobserved cues never match by being absent. Conflicting examples remain uncertainty, not a hidden correct-answer override. Unknown exceptions yield no supported repair recommendation, allowing ordinary help/defer opportunities. Repeated successful practice can strengthen a method; one lecture does not guarantee mastery. This is an engineering model of bounded method acquisition, not a universal planner or calibrated human learning.
