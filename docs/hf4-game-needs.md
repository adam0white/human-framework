## Rules and evidence

- Every faculty remains on. Removed `enable*` switches are migration hazards, never requests to restore a switch. Differences belong in authored state and ordinary inputs.
- No game code belongs in `packages/human`. World rules, authored plots, rendering, transport and game difficulty stay in each host. Generic actor inputs, readings, clocks and replay belong to HF.
- A missing 3.x export alone proves a bridge must change; it does not prove a faculty is missing. Use the eight-call run API. New outputs go through `inspect` or `preview`; new inputs go through `step`.
- Old saves may be refused with a start-fresh message. No 3.x continuation guarantee is requested. Every port must keep its exact package pin, seed, ordered input log, host state and `exportRun` archive; current-version exports must replay exactly. Preview must leave the live run unchanged. No game may silently turn an old export into a new run.
- The [published dispositions](releases.md#hf-40-game-dispositions-2026-10-27) supply the recorded reason for staying and the dated live pins. Source pins and bridge files below were read on 2026-10-27; they are not a new deployment audit. Source revisions are identified per game.
- Framework comparison uses published [4.0.0](../CHANGELOG.md#400---2026-10-27), `run-schema.ts`, `run-inspect.ts` and the existing [4.1 queue](roadmap.md#hf-41-deferred-from-40-ruling-25-owner-approved-2026-10-27). Work items reuse that queue rather than create duplicate faculties.

A cheap scratch consumer used the actual npm 4.0.0 tarball and the unchanged runtime import lists from Voice's `sim/game.ts` and Watch's `sim/night.ts`. Voice lacks 18 of 19 imported runtime names; Watch lacks all 18. Module loading fails before game execution (`MINUTES_PER_DAY` and `finish`, respectively). This is a narrow API compatibility check, not a port or a performance proof. No probe is merged. The observer and quantity gaps are independently visible in [`run-preview.ts`](../packages/human/src/run-preview.ts), [`run-inspect.ts`](../packages/human/src/run-inspect.ts) and the published root exports. Smoke and Child already have stronger scratch migration evidence recorded in [findings](findings.md#hf-40-step-cost-before-release-2026-10-27); their known failures are reused. Other bridges receive source inspection only where a useful executable probe would require a full port. No playtests or panel runs were performed.

The input id, evidence id and outcome id must be equal: reuse the actual outcome identity, not a fresh delivery identity. Ordinary input admission rejects repeat delivery. There is no automatic benefit for the mere presence of a voice.
- **G15:** sustained awake focus contributes to the existing bodily depletion store even below the physical-effort floor. Assume 0.03 per hour of the remaining store at full focus. Keep existing awake-rest and sleep recovery; asleep focus contributes nothing. This rate is an explicit engineering assumption, not a measured effect or a repair-world model.
