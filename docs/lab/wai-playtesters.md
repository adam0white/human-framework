The scheduled daily run first reads one rotating game, then proposes shared narration variants, then refreshes inbox suggestions, and finally runs focused playtesting and an A Dark Room control if budget and time remain. The focused game rotates across the registry. The current plan has one focused player and one control, both free to stop immediately. The focused task is one meaningful decision, its observed consequence and a final report, with a 25-minute ceiling. The control attempts one opening decision, its consequence and a report, with a five-minute ceiling. It checks the same input and reporting path on an independent game; it is not a matched comparison of game quality or a whole-game completion test.
