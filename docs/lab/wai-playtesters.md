# Daily Workers AI players

The runner uses Protocol 2 in `playtester-prompt.md`. It gives each model only live player-visible text and accessible controls from `lab:play`. It does not supply source, network payloads, exports or debug state. This is synthetic playtest evidence. A failed or interrupted run remains incomplete.

Run `/opt/homebrew/bin/node scripts/lab-wai-play.ts --plan` to inspect the daily plan without network calls. The default command (or `--run`) authorizes inference and starts the driver. Reports go to `~/code/.lab-scratch/wai-daily/<UTC-date>/`. A process lock prevents overlapping daily runners; an existing date plan prevents accidental repeated spending. Remove a stale lock only after verifying no process is active. Remove no receipts to retry a date.

Each day selects three registry games, one per model. The day index advances by three games, covering every registry game within a week. Each game gets identical persona text in free-stop (floor 0) and continued-exposure (floor 15) arms. Both have a 25-minute gameplay ceiling. One desktop A Dark Room session supplies the round control. Personas rotate weekly among the panel’s Maya Chen (curious), Emre Kaya (patient) and Nia Okafor (impatient). Their full personal briefs come from lab-personas.md. No persona is assigned a targeted-dislike probe. Stops during continued exposure do not measure voluntary stopping. A reader blind to the arm still needs to code the earliest wish to leave from the original diaries; the runner does not fabricate that independent reading.

Configured models are Qwen3 30B A3B FP8, Llama 3.2 3B Instruct and Llama 3.2 11B Vision Instruct. The live Cloudflare catalogue must confirm availability before any inference. Missing models are recorded as skipped. The vision model receives a current viewport screenshot per decision through the documented image byte-array input. Text models mark screenshot-dependent judgments `NOT TESTED`. No model licence is accepted automatically; a licence rejection stops the run.

Every model call goes through `lab-wai-budget.ts`. The shared account may have unrelated spending. Analytics may lag or be wrong. The hard local limit of 2,000 neurons per UTC day takes precedence over using the full free allowance. Account high-water gates add protection; they do not justify claiming exact account-wide free-tier safety. The local lifetime dollar cap leaves a separate allowance for the host translator. Reservations are charged before requests; unknown outcomes retain their reservation. Usage-limit errors and disk space below 5 GB stop the run. A budget stop can leave many planned sessions unplayed. That is a coverage gap, not a player quit or a negative verdict on a game.

At a normal session end, the runner asks the model to use the game's normal Send feedback controls, with name `playtester <persona> wai-<model-short-name>`. This is the owner's explicit exception to the canonical prompt's telemetry prohibition. It does not change consent settings. The closing stage has at most two minutes; gameplay stops at 25 minutes. A Dark Room has no HF feedback submission. A feedback submission is confirmed only by a visible receipt in the saved transcript. `report.json` deliberately makes no automatic sent claim.

The original model responses and visible snapshots are retained in `model.jsonl`. `wall-clock.jsonl` records driver inputs and diary entries. `report.json` stores the model's final report without inventing missing checkpoint answers. `usage.json` records the shared budget summary, including per-model neurons and dollar estimates. No claim that an exported run replays is made without a separate replay check.

Install the opt-in local timer with `/opt/homebrew/bin/node scripts/install-wai-daily.ts`. It writes and bootstraps a LaunchAgent. launchd checks at minute 40 each hour; the script exits unless the clock in America/Chicago is 19:40. This keeps the requested Chicago time year-round: 00:40 UTC during CDT and 01:40 UTC during CST, both after the daily reset. The Mac currently uses America/Chicago; if its system timezone changes to a half-hour offset, reinstall a suitable local timer. The computer must be awake and the signed-in session active. No catch-up or retry spending is scheduled. Uninstall with `launchctl bootout gui/$(id -u)/work.adamwhite.lab-wai-play`, then remove that plist.

`--suggest` adds a Clef classification of a completed model report through the same budget guard. It writes suggestion.json only and never edits a feedback ledger.

The scheduled job enables --suggest. After a round without a budget stop, the runner also refreshes lab:inbox suggestions. These are optional model classifications, never ledger decisions. On interruption, report.json and the final daily summary preserve partial evidence and accounting. Each vision decision keeps its own screenshot; feedback-receipt-or-failure.png records the last closing screen. Absence of a receipt remains an unverified submission. Invalid model JSON gets one correction attempt, then a TOOL interruption. These synthetic players provide weaker evidence than owner and friend playtests; reproduce their reported problem before treating it as established.

The daily model order rotates to avoid always spending the limited allowance on Qwen first. The three free-stop sessions run first, followed by the three continued-exposure sessions, then the single control. This is a limited recurring-player instrument, not a full panel round: the two never-HF cold positions and durable personal-diary continuity are omitted. That limits claims about novice reception and longitudinal character recognition. Each arm starts a fresh browser process; no prior arm transcript is supplied. Budget limits may prevent the paired session or control from running, and those missing comparisons remain explicit gaps.

Cloudflare's [pricing page](https://developers.cloudflare.com/workers-ai/platform/pricing/) confirms 10,000 free neurons per account per day on Free and Paid, reset at 00:00 UTC, with Paid overage $0.011 per 1,000 neurons. Checked 2026-10-23. `npm run lab:wai-usage` queries the account's `aiInferenceAdaptiveGroups` dataset with a UTC-day filter and `sum { totalNeurons }`. The field name was verified against the live GraphQL schema. See Cloudflare's [GraphQL reference](https://github.com/cloudflare/skills/blob/main/skills/cloudflare/references/graphql-api/README.md). Empty results mean zero only when the API returned the requested account and dataset successfully. Errors or missing data mean unknown, never zero.

The guard refuses a request whose conservative reservation would cross 9,500 account neurons. If analytics cannot be read, it also applies an 8,000-neuron local fallback ceiling. Its independent 2,000-neuron ceiling dominates both. It counts response neurons when provided, otherwise converts response token usage using published per-model rates; unknown usage retains the full reservation. It reserves the whole documented context for vision input. This deliberately leaves free allowance unused, because an account read that is completely wrong cannot guarantee free remaining capacity. The hard bound applies to these tools' own inference, not unrelated account callers.

The $5 experiment envelope is split into $4 for local scripts (including $0.207 debited for prior documented triage, inbox and island experiments) and $1 reserved for the public translator. Local budget state is private in `~/code/.lab-scratch/wai-daily/budget.json`; do not delete it to reset spending. Per-request reservations and an exclusive file lock cover concurrent script invocations. A crash retains its reservation. Inspect the exact PID in budget.lock before recovery. Neither the runner nor LaunchAgent commits to git.

Chosen active catalogue pages: [Qwen3 30B](https://developers.cloudflare.com/workers-ai/models/qwen3-30b-a3b-fp8/) for stronger text reasoning, [Llama 3.2 3B](https://developers.cloudflare.com/workers-ai/models/llama-3.2-3b-instruct/) for a fast small-model comparison, and [Llama 3.2 11B Vision](https://developers.cloudflare.com/workers-ai/models/llama-3.2-11b-vision-instruct/) for screenshots. The vision model may require a licence agreement; this job does not send an automatic acceptance request. Availability is checked live before each daily plan runs.

Reports reach the notebook inbox through the same player-facing Send feedback form used by people. Clef suggestions are local labels for a person to review. `lab:inbox --suggest` sends only note words and source kind. Neither path routes or edits ledger entries. Coordinator handoff lines go to `~/code/.lab-scratch/sweep/wai-ledger.md`; a person decides what belongs in the project ledger.

For an explicitly authorized retry, use `--attempt=<label>` to preserve the original day's receipts in a separate `attempt-<label>/` folder. This changes no UTC budget accounting and grants no additional allowance. `--probe=<registry-game-id> --attempt=<label>` runs only one Qwen free-stop session to check real input and normal feedback behavior. It is a format-and-feedback probe, not a complete protocol round. Prior attempts remain evidence, including failures. Qwen disables thinking; text models request JSON output. Missing text, invalid operations and unobserved future diary entries are not accepted as play evidence. Owner, friend and independent Codex observations are stronger evidence than these synthetic players.
