## The driver (the only way you touch the game)

Use Bash only to run curl against your two driver ports (never to write files), exactly in this form, one curl per Bash call:
  curl -m 40 -s -X POST http://127.0.0.1:PORT/ -H 'content-type: application/json' -d '<one JSON op>'
If a text value contains an apostrophe, write it as ' inside the single-quoted JSON. The game receives the same character you meant.
Each reply gives visible page text and an accessibility list of controls. Ops:
- {"op":"open"} first, once per session (starts that session's clock).
- {"op":"tap","name":"<exact full control name>"} (optionally "role"), or {"op":"tap","text":"<visible text>"}, or {"op":"tap","x":N,"y":N} for a point read from a screenshot.
- Any tap may carry an optional "duration_ms":N (N from 100 to 5000). The press is then held for N milliseconds with a real native mouse press (desktop) or touch press (phone), then released. Without it the tap is a normal short tap.
- {"op":"select","label":"<select label>","option":"<option>"}; {"op":"type","name":"<field>","text":"..."}; {"op":"key","key":"ArrowUp"} (Playwright key names); {"op":"scroll","dy":400}; {"op":"wait","s":N} (N up to 30) for real waiting.
- {"op":"shot","file":"a-001.png"} saves a screenshot of what is on screen; view it with the Read tool on the saved path. Look at screenshots regularly, especially for maps, canvases and layout; the text list does not show pictures.
- {"op":"log","kind":"note|pulse|first_minute|want_quit|stop","reaction":"your words", "reason":"...", "engagement":N, "game_clock":"..."} writes your diary line. Any op may also carry "reaction" and "game_clock".
Copy the full control name from the latest reply for every named tap, using the exact full names, and choose select options only from the labels the current reply shows. Names can carry a suffix or a likely answer. If several controls match, the driver taps nothing and lists them; every error reply carries `clickable`, the current names, so choose again from that list. Never drop or hide an error reply. An error saying a control is disabled, absent or covered is the game's answer, not a tool failure.
