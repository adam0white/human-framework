# Seven one-day gates: inputs to HF 4.0 (2026-10-26)

These seven later tests are distinct from the [eight first H3 bets](../../hf-roadmap-2026-10-20.md#horizon-3-long-bets) dated 2026-10-25. None is human replication. No negative or weak baseline was retuned. [Findings](../../findings.md#bounded-scratch-gates-2026-10-26) records the finite methods and metrics; the [capability table](../../framework.md#capability-evidence-2026-10-26) separates public APIs from scratch mechanisms.

- **Fable A, held purpose: NO-GO.** Ten seeds compare a categorical host-authored purpose request, the omitted slice and the actual HF 2.14.1 historical baseline. Median non-replacement placement events were 2 versus 2; paired median gain was 0. Forty-one physical replays and omitted full Person/RNG boundaries matched. Existing host-authored routes remained available. Placement events are not distinct retained objects. This does not test current 3.2 self behavior or autonomous route discovery.
- **Astra A, causal relations: restricted toy GO.** Ten seeds across four unseen layouts yielded 40/40 successes, versus 1/40 for the tested methods/planning arm and 3/40 without learning; all ten counterexamples revised the unconditional hypothesis. The review checked 424 recorded transitions. The relation vocabulary, two candidate hypotheses, visible state and goal item were authored. The baseline lacked unseen goal mapping. This does not defeat the strongest host encoding or establish integrated HF continuation; no learned-causal API shipped from this probe.
- **Astra D, portable runs: execution GO; independent third-world admission FAILED; combined REQUEST CHANGES.** A Node VM wrapper passed 588 interleaving, full-envelope restore/replay, RNG and version checks for two configured villages. World RNG advanced; person RNG stayed static. A fresh reader supplied an orbital-repair adapter through the documented contract; admission threw `Error: adapter version` before stepping. The wrapper hard-codes the village and offers no extension entry point. Empty features and fixed clocks bound the result; browser portability and arbitrary event replay are untested. This is a contract failure, not a failed orbital simulation.
- **Fable D, sleep proxy: NO-GO.** Fixed 4h/6h schedules compared normalized HF capacity and perceived sleepiness against reconstructed published power-law fits, not raw group means. Objective RMSE was 0.2571/0.1030 against a maximum 0.10; the 4h late-deterioration fraction was 0.0851 against a minimum 0.25. Capacity is not a validated PVT measurement; perceived sleepiness is not a validated SSS rating; actual sleep is not time in bed. Laibson's theoretical equation comparison failed numeric identity (delayed route/direct ratios were 0.9 of the stated curve); transcription remained provisional. Roberts supplied abstract directions only: 3/6 checks failed and two facets lacked mappings. Inverse HEXACO emotionality is not measured Big Five stability. The 1,884 internal arithmetic checks establish neither empirical fit nor human prediction.

- **Astra C, fiction: NO-GO for insufficient participation evidence.** All four fixed live/rehearsal/observer/strict-rehearsal offers were declined; actual participation was zero. Four full raw restored continuations and both RNG streams matched, but no active separation branch ran. Conditional successes on unreached branches are vacuous. Stage injury/debt, real versus role insult, assertion classification and strict-held reading remain untested. Independent review retains dormant P2: role intention is stored but never guides role choice. It did not affect these declines and does not establish an executed separation failure.
- **Fable B, second-order attribution: scratch GO within a finite depth-2 gate.** Ten fixed seeds passed 52 assertion groups, not 52 distinct phenomena. Actual HF perception admits only attended reports into a host-side JSON store. Current departure retains attribution; retrospective archive evidence about absence at the original event withdraws it. That archive can be incorrect and changes held attribution, not event truth. Privacy/attention negatives, omitted continuation and interleaving passed; JSON restore is bounded to the admitted envelope. Subjects A/B/C, one event, three records and four evidence entries bound the prototype. Seeing-implies-believing, reliability 0.8/1.0 and threshold 0.75 are authored conventions. No public Person API, decision benefit, general theory of mind or human validation follows.
- **Astra B, shared plans: NO-GO.** Candidate and capable ordinary-joint control both completed 10/10; delta 0 fails the required gain of at least 3 (candidate minimum 8). Both arms receive matched offers, messages, timing and own decisions; control can form a fresh second-stage team. Actual HF joint calls charge activity/time; the host authors allocation and resolves physics. Missing acknowledgement, unreceived amendment, withdrawal and focused busy/duplicate/stale guards passed within their reported bounds. Withdrawal checks completion safety, not immediate renegotiation; cloned-state guards are not broad scheduling proofs. Full JSON save/resume matched at minute 6, not arbitrary active-activity recovery through HF restore. A pre-outcome mirror-argument error was corrected before the successful run; the failed attempt remains retained. No post-result tuning occurred.
