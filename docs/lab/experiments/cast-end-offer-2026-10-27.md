# End-of-game person offer (2026-10-27)

The end screen offers a known person and up to two games from the cast registry. The player can save the chapter and follow a game link. Continuity runs automatically on this browser; the offer is an experiment in whether a natural stopping point helps players find another game. A link is not evidence that the destination has admitted the person: that game's admission checks still apply. Record player observations and whether the destination accepted the person before judging the experiment.

The shelf supports inspection, download, deletion and importing a separate branch. It cannot checkpoint a running game or start a fresh branch from that game by itself; the end-screen save uses the live game. A Selin return requires her original Voice chapter on this browser and a Good Hands return on the shelf.
