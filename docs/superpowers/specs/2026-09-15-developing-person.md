# Relationships, understood duty, and adult development

The user authorizes sequential autonomous gap implementation and targeted subagents before another game. This architectural increment composes private candidates without editing released modules. The aim is executable coverage of three bounded missing capabilities, not completion of empirical or interpretive validation.

1. Relationships: one actor owns contextual expectations, continuing care ties and delivered interaction evidence. Actual help can occur without a promise. Failed aid and acknowledged repair can change later coordination; hidden outcomes, apologies alone and inferred motives cannot. The host owns availability, transfer and recipient choices.
2. Understood duty: source references, scenario interpretation, the actor's understanding and private stated intention are distinct from attempted action, actual restitution and recipient response. A sourced entrusted-property case motivates costly repair. It does not compute fiqh, sincerity, forgiveness or divine acceptance.
3. Adult development: explicit adult calendar and role/opportunity history across months/years. Qualification and role transitions can change available actions; chronological age alone cannot grant competence or impose decline. Unmodeled intervals stay explicit; minute body coefficients are not extrapolated over years.

Each module is pure, deterministic, bounded, owner checked and JSON restorable. New source remains private. Integration must show intervention -> delivered state -> choice input -> rule -> executed consequence. Controls use the same available information and actual physics, including a serious direct rule. A separate package/consumer checks reusable exports. New version 0.1.0 per component; Human 0.1.1, situated/sustained/cognition sources and public assets stay unchanged.

Primary rejection checks: adding records with no causal use, world truth leaking to actors, double ownership of canonical outcomes, automatic forgiveness, intention producing resources, age granting skill, earned competence lost on role change, or claims of calibration from authored examples.
