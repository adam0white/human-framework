# Adversarial review of the HF roadmap, 2026-10-20 (Codex)

Raw final message of a read-only `codex exec` review of [hf-roadmap-2026-10-20.md](../hf-roadmap-2026-10-20.md) and the §3b diff in [roadmap.md](../roadmap.md), run with repository access. All fourteen findings were applied the same day (see the roadmap's Review section). Line numbers refer to the reviewed draft.

1. **Major — Contradiction is defined too broadly.** [New roadmap:67](docs/hf-roadmap-2026-10-20.md:67) lowers trust when different sources disagree. [The actual request:157](docs/game-requests-2026-10-18.md:157) concerns incompatible stories attributed to **one source**. **Fix:** require evidence of that source’s conflicting statements. Test that independent disagreement alone causes no penalty.

2. **Major — Believed standing lacks a consistent knowledge gate.** [New roadmap:68](docs/hf-roadmap-2026-10-20.md:68) and its proof at line 75 condition updates on what the _other_ witnessed, without consistently requiring the subject to know they witnessed it. **Fix:** require the subject’s attended evidence that the other knows. Add secret-witness and private-relay cases that leave the subject unchanged.

3. **Major — The promisee does not automatically update.** [New roadmap:68](docs/hf-roadmap-2026-10-20.md:68) says their “own impression already moves.” [`recordMissed`:484](packages/human/src/person.ts:484) updates only the breaker, with `byMe: true`; [`SOCIAL_EVENT_EFFECTS`:122](packages/human/src/social/social.ts:122) gives that side zero relationship change. Hosts can deliver a percept that changes the promisee’s relationship. **Fix:** state that delivery requirement and distinguish relationships from `social.impressions`.

4. **Major — The next increment’s proof can pass without its advertised behavior.** [New roadmap:75](docs/hf-roadmap-2026-10-20.md:75) chiefly prohibits changes and requests a report. Standing that never updates passes its negative assertion; no explicit conflicting-testimony event exercises contradiction; metadata-only provenance need not change decisions. **Fix:** specify positive standing and repair outcomes, an explicit contradiction event, and expected results for each ablation. Test metadata preservation separately.

5. **Major — Deliberate lying already shipped.** [New roadmap:162](docs/hf-roadmap-2026-10-20.md:162) defers “deliberate lie as an act” to H3. [`converse`:274](packages/human/src/conversation/conversation.ts:274) selects deceptive claims from temptations; [line 305](packages/human/src/conversation/conversation.ts:305) emits the speaker’s `lying` violation. **Fix:** mark tempted deliberate deception as existing. Defer the unified speech-act grammar and unsupported forms of deception.

6. **Major — Horizon 2 proofs omit their new faculties.** [New roadmap:108](docs/hf-roadmap-2026-10-20.md:108) tests sleep-awareness separation, already partly covered by [`body.test.ts`:160](packages/human/test/body.test.ts:160), without testing quantity estimation, dozing or bladder. Line 109 tests lens purity without testing method or response revision. **Fix:** add a positive behavioral assertion and disabling control for each advertised addition.

7. **Major — Done-means contains an impossible request mapping.** [New roadmap:146](docs/hf-roadmap-2026-10-20.md:146) assigns asks 1, 2, 4 and 7 to “Stairwell and Hearsay.” [Hearsay has three requests](../hearsay/docs/hf-requests.md:5), and its second remains outside the proposed implementation. **Fix:** write “Stairwell 1, 2, 4 and 7; Hearsay 1.” Include the prerequisite Host kit’s §1.2 proof explicitly in acceptance.

8. **Minor — The promised ledger removal exceeds scope.** [New roadmap:73](docs/hf-roadmap-2026-10-20.md:73) promises both games can drop host ledgers. Line 66 leaves the graph host-owned; line 77 excludes word returning to the subject, which [Stairwell’s ledger supports](../stairwell/docs/hf-requests.md:8). **Fix:** promise removal of provenance-matching workarounds; retain host graphs and disclosure policy.

9. **Minor — Demand counts overstate the priority evidence.** [New roadmap:55](docs/hf-roadmap-2026-10-20.md:55) claims “about ten” provenance/lineage asks. The direct requests are [Stairwell 4](../stairwell/docs/hf-requests.md:8) and [Hearsay 1](../hearsay/docs/hf-requests.md:5). Its three-game narration count also excludes Valley, explicitly included at line 89. **Fix:** count direct requests separately from the broader social cluster and enumerate narration’s contributing games.

10. **Minor — Warren’s requests are incompletely mapped.** [New roadmap:81](docs/hf-roadmap-2026-10-20.md:81) and [roadmap:136](docs/roadmap.md:136) place Warren 1 under travel/setup cost, but [Warren 1](../warren/docs/hf-requests.md:5) concerns need-term scale versus effort. [Warren 6](../warren/docs/hf-requests.md:15), material narration assuming money, is missing. **Fix:** add the motivation recipe explicitly and triage Warren 6 into narration.

11. **Minor — Targets remain contradictory.** Community/world migration is [unscheduled at roadmap:61](docs/roadmap.md:61) but assigned [engine 2.15 at line 138](docs/roadmap.md:138). Culture is [unscheduled pending review at line 101](docs/roadmap.md:101), while [the new roadmap:112](docs/hf-roadmap-2026-10-20.md:112) places it within the seasonal delivery horizon. **Fix:** reconcile duplicate rows and distinguish review dates from delivery commitments.

12. **Major — “World migration steps” cross the framework boundary as written.** [New roadmap:110](docs/hf-roadmap-2026-10-20.md:110) and [roadmap:138](docs/roadmap.md:138) place them in an HF release. [The architecture:157](docs/framework.md:157) assigns world state to hosts; [`World`:114](packages/human/src/sim/sim.ts:114) is an adapter interface, not a shared game-state schema. **Fix:** limit HF implementation to community migration; make world migration a host contract or recipe.

13. **Minor — Historical timing is presented as current.** [New roadmap:97](docs/hf-roadmap-2026-10-20.md:97) labels approximately 1.8 seconds “Today.” The matching evidence is the [2026-10-04 libm benchmark](docs/findings.md:105), not HF 2.9.0. The 18-minute annual estimate inherits that limitation. **Fix:** date the measurement and label the extrapolation, or measure the current release. Warren’s 4–10 ms and Valley’s quoted save sizes are supported by their request files.

14. **Minor — The proposed quantity API reuses an existing public name.** [New roadmap:108](docs/hf-roadmap-2026-10-20.md:108) proposes `estimate(p, { truth, difficulty })`; [`estimate`:383](packages/human/src/social/impressions.ts:383) already estimates another person’s characteristics. **Fix:** name it `estimateQuantity`, or explicitly require a compatible overload.

The recommended increment has identifiable scope, but its knowledge rules and acceptance criteria need correction before approval. The main release retargeting agrees with the edited §3b; duplicate targets remain unresolved. I found no explicit ruh quantification, scalar spiritual faculty, computed divine acceptance, invented ruling, LLM-in-loop requirement or seeded-determinism violation. World migration needs an explicit host boundary. No files were edited.
