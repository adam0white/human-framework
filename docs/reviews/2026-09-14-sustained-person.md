# Sustained-person review disposition

Independent review covered learning causality, continuous lifecycle ownership, host integration, package portability and the delivered claims. Reviewers used source inspection, focused tests and concrete counterexamples. No external service received private repository content.

## Fixed material findings

- The first host consumed food in its world but omitted the Human meal receipt. Actual consumed meals now apply relief once; each actor's meals debit the finite shared inventory.
- A recipient response read world supply directly while describing it as an observation. The host now delivers the relevant observation and the recipient's policy reads its own record. The direct duty rule also reads the actor's received commitment status.
- Intended interruption, recovery and delivery paths were unreachable under the initial effort/schedule combination. The declared reference schedule now reaches those paths; short sleep still changes a real capacity outcome. The scenario is an authored software experiment, not physiological calibration.
- The first recovery rival was numerically identical and the direct-policy switch was unused. The instant-sleep-recovery control is now distinct; direct rules use received facts and a no-decay notebook. Parity remains in the report.
- Raw float equality was incorrectly required for alternate clock drivers. Body comparisons use the declared 1e-9 numerical resolution; actions/world outcomes and ordering must still agree. Learning clock advancement itself is exactly compositional.
- Learning evidence could be transplanted between actors. The composed state now binds it to the person's ID and rejects a different owner's subtree.
- Diagnostic learning records exposed reported content despite low accessibility. The diagnostic remains explicitly researcher-facing; the composed actor view omits content, and `retrieveLearning` applies an explicit access threshold. Tests cover unavailable content and preserved diagnostic evidence.
- New construction at a nonzero time conflicted with the condition initializer. The constructor now explicitly requires zero-time creation; continuation uses validated restore. No past sleep history is invented.
- The independent consumer originally reported only an access difference. It now makes retained access avoid a paid source consultation, preserves success for the consultation control, and compares resumed with uninterrupted continuation state.

## Retained boundaries

Learning and food receipts are host attestations. Their structure and chronology can be checked, but a component cannot prove a world event without owning that world. Ninety days is a hard default candidate horizon; the full bounded receipt set is retained, while recent evidence display is separately limited. Sleep/retention rates, decision thresholds and the idealized instant recovery rival are authored engineering assumptions. The experiments establish executable behavior and independent installation, not empirical accuracy, model superiority or measured human authoring savings.

The exact final test counts, source identities and comparative outputs are recorded in `artifacts/sustained-person/verification.json` and the adjacent comparison and consumer reports.
