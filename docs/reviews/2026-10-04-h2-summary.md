# Review actions, H2 (HF 2.0), 2026-10-04

What was done about each finding in the three H2 reviews of everything since R2 (73f063a): [performance](2026-10-04-h2-perf.md) (Opus, adversarial, measured), [quality and API](2026-10-04-h2-quality.md) (Opus, persona: maintainer of a peer game-AI library, blunt about names) and [security](2026-10-04-h2-security.md) (Opus). One row per finding. Status is **acted**, **deferred** (with the reason and a target) or **rejected** (with the reason); findings that asked for nothing are **no action**. Targets: **2.1** is the next HF minor release, **G3-5** the next Game 3 pass after the user's playtest, **later** means after Goal 2.

The engine rule for this release: every HF change ships with a default that leaves a valid 1.9.0 run byte-identical, and games opt in. The proof is the 1.9.0 save fixture (it continues to the same digest once the one renamed field is written back) and Games 1–2's recorded playtests (they replay to the same state once the engine stamp is written back). Changes that would move every replay (per-minute catch-up, lazy decay, an age-bounded chronicle by default) are deferred to 2.1 with their own engine bump.

**Counts:** 78 findings: 38 acted, 30 deferred, 9 no action, 1 rejected ("acted" includes acted in part and opt-in).

## Security
