# App 0.11: The camp

Release candidate prepared 2026-09-08; exact deployment and production evidence will be appended after verification. Current live delivery remains app 0.10 until that step succeeds.

**The camp** at `/camp/` is one continuing game: build an actual camp, use what remains to provision households and camp before a ferry/rain window, then return to the same people, supplies and unfinished work. Automatic available-time recovery replaces finite rest assignments in default play. Construction preserves physical progress, prospective tool improvements and each worker's paid contribution; handovers require a capable, willing participant. A meal still reserves a real portion and takes paid time.

The interface keeps the compact HUD/tab vocabulary. Five separate slots preserve current stories when starting or importing another. Busy old Common Ground saves and existing Before-the-rain chapters have explicit previewed migrations; old files and game keys remain untouched. The ten original experimental games remain available as controls. [Interface and support boundaries](camp-interface.md).

The new versions are camp **0.2.0/save 2** and story **0.1.0/save 1**, selecting frozen Human/runtime **0.1.1** and clock **0.1.0**. No old public host, runtime/model/clock, legacy engine or package export changed. This does not implement a universal campaign engine, a calibrated human model or all deferred faculties.

The integrated suite passes **685 tests** on Node 26.8.1. All new host/session/slot/comparison mechanisms have scoped minimum-Node-22 verification. Local browser checks pass **nine groups** spanning real paid actions, migration, phases, save isolation, error handling and responsive controls. Independent kernel, story and UI reviews and scoped corrections are retained. [Review dispositions](reviews/2026-09-08-earned-camp-review.md).

The final 26 development plus three previously reserved records replay exactly on minimum Node 22. Policies are unchanged; the already unsealed boundary cases are labeled post-review validation. Both simple policies still complete five caches at the shared budget. A competent faster snapshot validator remains in the evidence alongside the journal's narrower integrity benefits and load cost. [Reviewed comparison](camp-comparison-reviewed.md) · [Validator tradeoff](camp-validator.md).

The local build has **91 public files, 61 JavaScript modules and 99 static import edges**; deployment dry-run passes. Exact live payload and production browser verification remain required before delivery is claimed.
